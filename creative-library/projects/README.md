# Creative projects

## Existing projects

- [Main-page animation](main-page-animation/composition-baseline.md): the owner's
  saved layout/density reference, distinct from the preserved live-house artwork.

For a new animation or substantial design change, create a named folder here
and copy [the design brief template](../templates/design-brief.md) into it.

Add `originals`, `working`, and `previews` subfolders only when needed. Keep
source/license records next to retained artwork. Preserve candidate versions,
preparation recipes, preview dimensions/times, and the owner's actual decisions.
Never replace the live scene merely to demonstrate an alternative.
