Welcome to Grim Gatherings

A story-led murder-mystery party for friends, with the host's narration on one device and each guest's character and clues on their own phone. You can use a ready-to-play mystery or write one in the workshop. Accounts are optional for playing.

Your story game in three steps

  1. Prepare the gathering. Choose Create a new game, add each player's name, and pick a mystery written for exactly your group's size. Review the story and assign characters. The host narrates and only counts as a player if assigned a character too.
  2. Open the doors and meet the cast. Open the lobby before sharing its QR code or room link. Guests scan or enter the code, choose their assigned name, and read their character invitation. The host reads the setup aloud, then each player reads their character card aloud around the group. The group may discuss or accuse based on the introduction alone before starting.
  3. Follow the clue chain. The first scheduled player reads a clue about another character. The character talked about reads next, continuing by target until everyone has read once; if that loop closes early, the next unread player starts again. Discuss and vote after every round. Repeat the chain for each round; after the final round, make final accusations and cast the final vote. Then choose Reveal the truth and read the complete fixed story. After the host confirms End game, the host returns home and connected guests can choose Return home.

Every story, including both premium stories, has one fixed player count and a chain/coverage schedule written in advance. The first N−1 rounds give every player one clue about every other player exactly once. Any extra rounds follow the story's event arc, occur only after that complete coverage, and may repeat a reader-target pair only where the story notes why it requires it. Clues are read aloud and target another character; story-specific mechanics come from that story's events. Do not inspect the host's story review if you want to avoid spoilers. Murderer identity notification is an optional host setting; it is off by default.

Optional premium games follow the same universal flow and are each written for exactly five players. Only the host buys the $9.99 USD two-game bundle. In the shop, choose Host a room and share the eight-character code or joining link. Guests join the premium room free on their own phones without accounts. Check all lobby names before starting. The host advances setup, discussion and vote phases; players read their assigned character cards and clues aloud and vote when it is their turn. The group deliberates and votes after every round, makes final accusations and a final vote, then hears the fixed full-story reveal. A playing host joins a player seat too; a non-playing host uses only host controls. Keep the same browser to reconnect and finish within 24 hours. Optional pass-and-play follows the same flow. The shop tells you whether purchases are open.

Devices, connections & saved games

Use a current Safari or Chrome browser and an internet connection on every device. A laptop or tablet is ideal for hosting. The host browser runs the room: keep the game screen open and the device awake. We request screen sleep prevention where the browser allows it, but this cannot keep a closed laptop, locked device or suspended browser running.

If someone disconnects, leave their character assigned. Phones retry automatically and keep their last received clues; votes wait until reconnected. Return to the host screen or choose Reconnect room. Do not create a new room just to repair a connection.

If you reload the host or return home, choose Resume on the same browser and device to reopen the saved room. Guests keep the same link and character. Browser Back preserves your saved game. Creating a new game or replacing a mystery asks for confirmation before discarding the old room's progress.

Save an edited mystery to My Stories or download its JSON before ending a game. A saved mystery is separate from live progress. Local saves are not an account backup and can be lost if you clear browser data. Optional workshop accounts provide creator draft backups, not live-game cloud hosting.

If a room cannot connect, check its code, ask the host to open the lobby, and make sure the host is awake and online. Some restrictive networks block peer-to-peer connections; try another network or browser. A sleeping host temporarily pauses the game rather than providing always-on server hosting.

Contact & support

Report bugs or ask general questions through our GitHub support tracker. Include the browser, device, steps to reproduce and any non-sensitive error message. A GitHub account is needed to post.

Reports are public. Never post passwords, API keys, account tokens, live room links, unpublished stories or personal information. For an account or privacy question, ask the owner for a private contact method without posting your account details.
